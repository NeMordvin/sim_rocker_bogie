# Отчёт о тестировании

Дата прогона: 3 сентября 2026 года.

## Окружение

- Python 3.12.13
- NumPy 2.5.2
- SciPy 1.18.1
- pandas 2.3.3
- Plotly 6.9.0
- Streamlit 1.63.0

## Автоматические тесты

Команда:

```bash
python -m unittest discover -v
```

Результат: **19 из 19 тестов пройдены**, ошибок и пропусков нет. Время полного
прогона — 14,423 с в тестовом окружении.

Проверены:

- отсутствие размеров и столкновений корпуса в модели;
- допустимость исходной геометрии и ограничение общей длины;
- вычисление длин и углов звеньев из независимых координат;
- геометрическое прохождение ступени в обоих направлениях;
- разрешённая потеря одного колёсного контакта над рвом;
- валидация массы, колеи, сцепления, момента и центра масс;
- сумма нормальных реакций и расчётный вес `m·g·Kд`;
- симметрия реакций на одинаковом профиле;
- невязки баланса сил и моментов;
- отказы при недостаточном моменте и сцеплении;
- поперечная устойчивость с учётом колеи и смещения ЦМ;
- крен и поперечные реакции на односторонней ступени;
- равновесие при потере контакта над рвом;
- проверка обоих сценариев ступени;
- бинарный поиск с повторной проверкой найденного предела;
- строгая последовательность «оптимизация ступени → расчёт рва победителя»;
- наличие полного расчёта и ссылок в каждом ключевом кадре;
- отсутствие кадров анимации в фигурах Plotly;
- открытие всех пяти вкладок Streamlit без исключений.

## Контрольные численные результаты

Для параметров по умолчанию (`m=120 кг`, `Kд=1,2`, `g=9,81 м/с²`):

- расчётный вес — `1412,64 Н`;
- сумма шести нормальных реакций на горизонтальной поверхности — `1412,64 Н`;
- максимальная невязка сил — `2,274·10⁻¹³ Н`;
- максимальная невязка моментов — `2,842·10⁻¹⁴ Н·м`;
- реакции и моменты левого и правого бортов совпадают на симметричном профиле;
- односторонняя ступень создаёт ненулевой крен и поперечные реакции;
- для рва найден допустимый кадр с четырьмя оставшимися контактами.
