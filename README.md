# Геометрическая оптимизация Rocker-Bogie

Программа подбирает размеры 2D-шасси с одиночным передним колесом и
косвенно-угловым П-образным bogie.

Проверяются:

- максимальная вертикальная ступень;
- максимальная ширина глубокого рва;
- движение одиночным колесом и bogie вперёд;
- столкновения колёс, корпуса и толстых рычагов с препятствием;
- непрерывность последовательности положений;
- для рва — положение проекции центра масс внутри продольного интервала опор;
- ограничение полной длины шасси.

Модель не учитывает трение, момент двигателей, деформацию колёс, прочность,
удары и динамику. Результат означает только геометрическую возможность.

Препятствие считается одинаковым под левым и правым бортом. Для классического
дифференциала угол корпуса равен среднему углу двух rocker. В такой симметричной
2D-задаче оба rocker имеют одинаковый угол, поэтому корпус и rocker на боковой
проекции поворачиваются вместе.

Для ступени решается квазистатическая обратная кинематика. Центр каждого
колеса движется по точному контуру контакта: нижняя площадка, вертикальная
стенка, дуга вокруг кромки и верхняя площадка. Во всех положениях каждое из
трёх колёс борта имеет контакт с поверхностью; кадры являются выборками
непрерывного решения, а не независимо подобранными рисунками. Главный шарнир
не обязан монотонно двигаться по X: при подъёме колеса по стенке он может
немного смещаться назад.

Требуемые моменты двигателей, сцепление и контактные силы пока не
рассчитываются. Для глубокого рва допускается неподдерживаемое колесо над
пустотой, но требуется минимум две разнесённые продольные опоры, между
которыми с заданным запасом находится проекция центра масс.

## Установка и запуск

Откройте PowerShell в папке проекта:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Если использовалось старое имя файла, оно также остаётся доступным:

```powershell
python -m streamlit run "app(1).py"
```

## Порядок работы

1. На вкладке **«Геометрия»** введите размеры.
2. Оставьте флажок **«Свободный»** только у параметров, которые разрешено
   менять оптимизатору.
3. В боковой панели задайте пределы шарниров, зазоры и максимальную длину.
4. На вкладке **«Пределы»** рассчитайте текущую конструкцию.
5. На вкладке **«Оптимизация»** найдите общий вариант для ступени и рва.
6. Примените лучший вариант, выполните точный расчёт и откройте
   **«Анимацию»**.

Заднее колесо имеет координату `X = 0`. Все X-координаты задаются относительно
него. В исходном положении центры трёх колёс автоматически находятся на одной
высоте.
