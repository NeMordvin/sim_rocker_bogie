# Оптимизатор подвески Rocker-Bogie

Streamlit-программа рассчитывает геометрию шестиколёсной подвески, прохождение
идеальной вертикальной ступени и рва, квазистатические реакции, сцепление,
моменты шести мотор-колёс, продольную и поперечную устойчивость.

Размеры и столкновения корпуса не учитываются. Общий центр масс задаётся
координатами относительно середины оси главных шарниров.

## Запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
```

Windows:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

Linux/macOS:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

## Мотор-колесо

Параметры по умолчанию соответствуют мотор-колесу Xiaomi M365 Pro: шина 8,5″
(наружный диаметр ≈216 мм, радиус 108 мм), 300 Вт номинально, 600 Вт пик.
Момент производитель не публикует; 16 Н·м — оценка пикового момента, её
следует уточнить замером.

## Два предела

Для каждого препятствия и направления программа считает:

- **геометрический предел** — существует непрерывный путь подвески без
  пересечений колёс и рычагов с препятствием и без выхода шарниров за
  диапазон;
- **физический предел** — вдобавок в каждом кадре выполняются уравнения
  равновесия с ограничениями сцепления, момента колёс и устойчивости.

Физический предел ищется внутри геометрического и указывает, что именно его
ограничило (сцепление, момент, опрокидывание или геометрия).

## Последовательность расчёта

1. Строится непрерывный 2D-путь одной стороны подвески. На ступени решаются
   четыре уравнения контакта (X, Y главного шарнира, угол rocker, угол bogie):
   ведущее колесо движется по контуру площадка → стенка → дуга вокруг кромки →
   верхняя площадка, два других касаются назначенных поверхностей.
2. Для каждого положения собирается шестиколёсная модель. Проверяются варианты
   препятствия по всей ширине и только под левой стороной, оба направления
   движения и работа идеального симметричного дифференциала.
3. Линейным программированием (HiGHS) решаются уравнения равновесия всего
   ровера, свободных шарниров bogie и дифференциала. Сила от грунта ограничена
   сцеплением `|T| + |Q| ≤ μN`; сила привода `D = T + crr·N` — пиковым
   моментом колеса. Тяга распределяется между колёсами оптимально (идеальное
   управление тягой): так задние колёса прижимают колесо к стенке, а трение
   на стенке поднимает его.
4. Опорный многоугольник строится только по контактам с положительной
   нормальной реакцией. Над рвом колесо может потерять контакт, если сохраняются
   равновесие и требуемый запас устойчивости.
5. Для ключевых кадров вычисляется требуемый коэффициент сцепления.
6. Оптимизатор максимизирует физический предел ступени в обе стороны:
   случайный перебор (латинский гиперкуб) → покоординатный поиск от лучшего
   варианта → точная проверка трёх лучших. Ров рассчитывается после выбора
   победителя и не влияет на геометрию. Варианты считаются параллельно на всех
   ядрах процессора.

## Ориентир для вертикальной стенки

Колесо, несущее долю веса `F` из `W`, поднимается по стенке, если остальные
колёса прижимают его достаточно сильно: `μ²·(W − F) ≥ F`. При равной нагрузке
колёс (`F = W/3` для одного борта) требуется `μ ≥ 0,71`. Кроме того, колесо на
стенке поднимает свою долю веса только своим моментом: `τ ≥ F·R`. Поэтому
положение главного шарнира, масса и момент колёс сильнее всего влияют на
физический предел.

Длины секций rocker и bogie и их исходные углы выводятся как производные от
свободных координат шарниров и колёс. Это исключает противоречивые комбинации
«координата + независимая длина».

## Ключевые кадры

Вместо анимации программа выбирает начало и конец прохождения, смены контактов,
кромки и стенку ступени, максимальный момент, максимальное использование
сцепления, минимальный запас устойчивости, максимальные тангаж и крен. В каждом
кадре показаны реакции, численные подстановки в формулы и ссылки на публикации,
использованные для этого расчёта.

## Тесты

```bash
python -m unittest discover -v
```

Набор проверяет геометрию, оба направления, допустимую потерю контакта над
рвом, баланс сил и моментов, пределы сцепления и приводов, требуемое сцепление
(на ровной площадке оно не нужно, на кромке растёт с нагрузкой колеса),
соотношение физического и геометрического пределов, совпадение параллельного и
последовательного расчёта, колею и поперечный центр масс, одностороннюю
ступень, порядок оптимизации, статичность кадров и запуск Streamlit-интерфейса.

## Ограничения модели

- Расчёт квазистатический; коэффициент динамики увеличивает расчётный вес, но
  не моделирует удар о кромку.
- Грунт и звенья считаются абсолютно жёсткими.
- Не рассчитываются прочность рычагов, деформация шин и грунта, нагрев приводов,
  люфты и упругость дифференциала.
- Условие совместного продольного и поперечного сцепления линеаризовано
  консервативной пирамидой `|T| + |Q| <= μN`.
- Распределение тяги оптимально (идеальное управление тягой); при одинаковом
  токе всех моторов фактический предел будет ниже.

Методика и ссылки на Hacot–Dubowsky–Bidaud, Papadopoulos–Rey, Lamon–Krebs и
материалы NASA/JPL также доступны на вкладке «Методика и статьи».
